## Introduction

One of the simplest explanations for the one-day dating errors in Lieutenant Colonel [Charles Halt]({{ 'charles-halt/' | relative_url }})'s January 1981 memorandum is also one of the most mundane: both incidents took place during overnight security duties that began on one evening but continued into the early hours of the next calendar day. If those events were later remembered by the evening on which the duty shift started rather than by the formal calendar date after midnight, both dates would naturally be advanced by one day when recalled from memory. This mechanism does not explain what witnesses did or did not see in Rendlesham Forest. Instead, it offers a plausible explanation for why Halt's official summary consistently listed **27 December instead of 26 December** and **29 December instead of 28 December**, with both errors moving in exactly the same direction. [Contemporary records]({{ 'contemporary-record/' | relative_url }}) and later historical reconstructions support the corrected chronology while leaving the memorandum itself unchanged.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ianridpath.com/ufo/appendix.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ianridpath.com">[Ian Ridpath]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ianridpath.com</span><span class="citation-popover-title">Ian Ridpath Appendix – Col Halt&#x27;s memo to the Mo D</span><span class="citation-popover-snippet">Ian Ridpath Appendix – Col Halt&#x27;s memo to the Mo D</span></span></span>

## Evening labels versus calendar dates

The reported events unfolded during the Christmas period at RAF [Woodbridge]({{ 'woodbridge/' | relative_url }}), when security personnel were working night shifts. Operationally, people often describe an overnight duty by the evening on which it began rather than by the date after midnight. A patrol beginning late on 25 December, for example, may casually be remembered as "the Christmas night shift" even though key events occurred around 3:00 a.m. on 26 December.

That distinction matters because Halt did not write his memorandum while the events were unfolding. His report, dated 13 January 1981, summarised incidents from memory more than two weeks after the first encounter and nearly two weeks after his own investigation. The document therefore represents a retrospective administrative summary rather than a contemporaneous operations log.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ianridpath.com/ufo/appendix.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ianridpath.com">[Ian Ridpath]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ianridpath.com</span><span class="citation-popover-title">Ian Ridpath Appendix – Col Halt&#x27;s memo to the Mo D</span><span class="citation-popover-snippet">Ian Ridpath Appendix – Col Halt&#x27;s memo to the Mo D</span></span></span>

Retrospective reports are especially vulnerable to date shifts when an event spans midnight. People often remember the evening they reported for duty more vividly than the moment the calendar changed, particularly when no significant break marked the transition from one date to the next.

## Why overnight duty causes date confusion

The pattern in Halt's memorandum is important because the mistakes are systematic rather than random.

The first reported encounter occurred at approximately 3:00 a.m., which is unambiguously after midnight. Modern chronologies place this on **26 December 1980**, yet Halt's memorandum recorded **27 December**. Likewise, Halt's own expedition into the forest took place during the early hours of **28 December**, but the memorandum recorded **29 December**.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://en.wikipedia.org/wiki/Rendlesham_Forest_incident" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: Wikipedia">[Wikipedia]</a><span class="citation-popover" role="note"><span class="citation-popover-source">Wikipedia</span><span class="citation-popover-title">Rendlesham Forest incident</span><span class="citation-popover-snippet">Rendlesham Forest incident</span></span></span>

Several features make an overnight-shift explanation plausible:

* **Both incidents happened during the same type of operational period.** Each involved overnight security activity extending into the early morning.
* **Both errors moved forward by exactly one day.** Independent typographical mistakes would not necessarily produce identical shifts.
* **The report was written from memory.** The memorandum was prepared weeks later rather than from notes made during the incidents themselves.
* **The times themselves were not altered.** The memorandum retained early-morning timings while attaching them to the wrong calendar dates, consistent with remembering the surrounding duty period rather than checking a dated log.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ianridpath.com/ufo/appendix.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ianridpath.com">[Ian Ridpath]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ianridpath.com</span><span class="citation-popover-title">Ian Ridpath Appendix – Col Halt&#x27;s memo to the Mo D</span><span class="citation-popover-snippet">Ian Ridpath Appendix – Col Halt&#x27;s memo to the Mo D</span></span></span>

This mechanism requires no elaborate explanation. It depends only on the well-known tendency for overnight work to blur the distinction between an evening's shift and the next day's calendar date.

### Why memory and administration are not the same thing

Military personnel routinely keep detailed operational records, but not every later summary is created from those records. Halt's memorandum was a concise briefing for the Ministry of Defence rather than a minute-by-minute reconstruction.

Ian Ridpath's examination of the memorandum notes that the dates should read **26 December** and **28 December**, while also observing that other discrepancies in the memorandum appear consistent with imperfect recollection rather than deliberate alteration. Later research by David Clarke, based on interviews with those involved in transmitting and receiving the memorandum, likewise indicates that it served as an informational summary rather than a comprehensive investigative report.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ianridpath.com/ufo/appendix.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ianridpath.com">[Ian Ridpath]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ianridpath.com</span><span class="citation-popover-title">Ian Ridpath Appendix – Col Halt&#x27;s memo to the Mo D</span><span class="citation-popover-snippet">Ian Ridpath Appendix – Col Halt&#x27;s memo to the Mo D</span></span></span>

## Why both errors moved in the same direction

The strongest argument for the overnight-shift explanation is not that it can explain one incorrect date, but that it naturally explains **both**.

If Halt had simply misread a calendar once, there would be no obvious reason for the same one-day shift to affect two separate incidents occurring on different nights. By contrast, if he consistently associated each event with the evening on which the overnight duty began, both dates would be displaced in exactly the same direction.

This symmetry is significant because it points towards a single underlying mechanism rather than unrelated mistakes. The corrected chronology derived from police involvement, later documentary analysis and historical reconstruction consistently places the two principal episodes on **26 December** and **28 December**, matching the pattern expected if the memorandum's dates slipped forward during retrospective recall.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://en.wikipedia.org/wiki/Rendlesham_Forest_incident" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: Wikipedia">[Wikipedia]</a><span class="citation-popover" role="note"><span class="citation-popover-source">Wikipedia</span><span class="citation-popover-title">Rendlesham Forest incident</span><span class="citation-popover-snippet">Rendlesham Forest incident</span></span></span>

The explanation also fits later accounts. In subsequent interviews and recollections, Halt described the first incident as occurring during the night of **25–26 December** and his own investigation during the night of **27–28 December**, reflecting the corrected overnight chronology rather than the dates printed in the original memorandum.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://en.wikipedia.org/wiki/Rendlesham_Forest_incident" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: Wikipedia">[Wikipedia]</a><span class="citation-popover" role="note"><span class="citation-popover-source">Wikipedia</span><span class="citation-popover-title">Rendlesham Forest incident</span><span class="citation-popover-snippet">Rendlesham Forest incident</span></span></span>

## What this mechanism can—and cannot—explain

The overnight-shift hypothesis addresses a narrow but important historical question: why the official memorandum contains two one-day dating errors.

It does **not** establish whether the reported lights had an ordinary or extraordinary cause, nor does it resolve wider debates surrounding the Rendlesham Forest incident. Instead, it explains why an authentic official document can still contain chronological inaccuracies.

For historians, this distinction matters because chronology determines which [police records]({{ 'police-record/' | relative_url }}), [witness statements]({{ 'witness-dates/' | relative_url }}), astronomical observations and other contemporaneous evidence belong to each reported event. Correcting the dates does not diminish the memorandum's importance, but it does show why even official retrospective summaries must be checked against records created closer to the time of the events.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ianridpath.com/ufo/appendix.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ianridpath.com">[Ian Ridpath]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ianridpath.com</span><span class="citation-popover-title">Ian Ridpath Appendix – Col Halt&#x27;s memo to the Mo D</span><span class="citation-popover-snippet">Ian Ridpath Appendix – Col Halt&#x27;s memo to the Mo D</span></span></span>

    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
